## Notes de conception
- **⚠️ À CHAQUE LIVRAISON : changer le numéro de version PARTOUT, y compris dans le launcher.** Le numéro vient de `package.json` (`version`) ; c'est lui qui s'affiche dans le launcher (pastille `v…` de la barre de titre, `app.getVersion()`), dans le nom de l'exe, dans `latest.yml` et dans le tag `v…`. Vérifier que le même numéro apparaît dans : `package.json`, `package-lock.json` (les deux champs `version`), le titre de la dernière section de `docs/FICHE-DE-REPRISE.md` (+ sa première ligne), la ligne « Mise à jour » de ce fichier, le nom de l'archive livrée. Puis lancer `node test/version.test.js` (il vérifie `package.json`, la fiche et l'affichage dans l'interface).
- **Ton des règles et textes** : Hydarium n'a pas de structure (pas d'entreprise, pas de société). On dit « Hydarium » ou « l'auteur », jamais « notre société » ; on n'a pas non plus à préciser que ce n'est pas une entreprise.
- **Amis (10)** : demande sans pseudo à l'envoi (anti-spam), pseudo visible côté destinataire ; réinitialiser le code ami efface tous les contacts ; le code ami doit être flouté par défaut (mode confidentialité).
- **Mods d'un serveur hébergé (9)** : seulement vers les joueurs qui ont le launcher ; liste des mods + téléchargement automatique (Modrinth / CurseForge quand possible).
- **Interface (11)** : à faire en dernier ou par étapes ; il faudra décider d'un thème (carré par défaut, option pour revenir aux coins arrondis ?).
- **Version optimisée (12), ce qu'on sait de Horizon** (page du projet, relevée à la main, à revérifier le moment venu) : réécriture de Minecraft Java Edition **26.3** en Rust, programme natif sans Java, rendu Vulkan / wgpu, licence **MIT** (travail original ; dépendances sous leurs propres licences), lanceur à eux (Windows, macOS, Linux), vérifié contre le jeu d'origine par 281 « harnais » de comparaison. Ses auteurs annoncent, face à Java + Sodium + Lithium + FerriteCore + ImmediatelyFast sur un Ryzen 7 9800X3D / RTX 5080 : écran-titre en ~3 s au lieu de 11 s et **31 à 38 % d'images par seconde en plus** (chiffres d'eux, pas mesurés ici). Sur leur feuille de route : navigateur, Android / iOS avec mods.
- **Limites à regarder avant de s'y mettre** : (a) les mods Java (Fabric, Forge) **ne tournent pas tels quels** : Horizon a sa propre API de mods pour « porter vos mods en Rust », donc « compatible avec des mods » veut dire un écosystème différent, pas Modrinth tel quel ; (b) une seule version du jeu (26.3 au moment où j'ai regardé) ; (c) projet jeune et non officiel (« pas approuvé par Mojang ou Microsoft ») : maturité, stabilité des mondes et des serveurs à tester ; (d) binaire tiers à télécharger : vérifier signature / provenance ; (e) comptes Microsoft, serveurs, partage de mondes : comment ils sont gérés chez eux ; (f) licence et marque : MIT pour leur code, mais les ressources du jeu restent à Mojang (EULA). **Pistes d'intégration** : un « moteur » au choix dans la création d'instance (Java classique ou Horizon), en téléchargeant leur programme et en le lançant comme le fait déjà Hydarium pour Java ; commencer par un simple lien / test avant toute vraie intégration.
